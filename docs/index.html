Upgrading from Moonleaf v4.0.0 or macpaper

The original upstream repository (illufied/moonleaf) has been archived, meaning its automatic update checker can no longer receive new versions. Upgrading to this maintained fork is 100% seamless and safe.

1
Install the maintained version: Run brew install shiquda/moonleaf/moonleaf or download the latest moonleaf.dmg.
2
Non-destructive automatic migration: Launching Moonleaf automatically preserves and adopts your existing settings (~/.config/moonleaf) and downloaded wallpaper library (~/.local/share/paper/wallpaper). No data is deleted.
3
Enjoy future updates: Subsequent releases will be delivered automatically via the built-in Sparkle updater.

Frequently Asked Questions

Answers to common questions about Moonleaf maintenance, installation, and capabilities.

Is moonleaf still maintained?

Yes, Moonleaf is actively maintained. While the original repository (illufied/moonleaf, originally naomisphere/macpaper) was archived after v4.0.0, this fork (shiquda/moonleaf) continues active development with bug fixes, Homebrew packaging, and Sparkle updates. It requires macOS 12 or later; tested on macOS 26 Tahoe.

Can I set a different wallpaper on each monitor and virtual Space?

Yes. Moonleaf's Desktop Overview organizes active displays and macOS Spaces together so you can assign, shuffle, and track independent static wallpapers (.jpg, .jpeg, .png) per display and Space, with automatic recognition on launch. Video (.mp4, .mov) and .gif wallpapers play via the native desktop overlay across connected displays.

Does Moonleaf support wallpaper playlists and usage history?

Yes. You can create named playlists referencing wallpapers in your library without copying files, choose sequential or random rotation with per-list intervals (15 minutes, 1 hour, 3 hours, or Daily), and switch the current desktop's playlist from the menu bar. Moonleaf also keeps up to your last 1,000 successful wallpaper changes in Recent and Timeline views.

How do I upgrade from upstream Moonleaf v4.0.0 or macpaper without losing wallpapers?

Install via Homebrew (brew install shiquda/moonleaf/moonleaf) or download moonleaf.dmg from GitHub Releases. On first launch, Moonleaf automatically and non-destructively adopts your existing settings (~/.config/moonleaf) and wallpaper library (~/.local/share/paper/wallpaper). In Storage settings, Library files, External references, and clearable Download cache are clearly separated so clearing cache never deletes your saved wallpapers.

How do I install Moonleaf with Homebrew?

You can install Moonleaf with a single command:
brew install shiquda/moonleaf/moonleaf
Homebrew will automatically download, verify, and link Moonleaf to your Applications folder.

Does Moonleaf support Apple Silicon and Intel Macs?

The v4.2.0 release is a Universal binary for Apple Silicon (arm64) and Intel (x86_64) Macs running macOS 12 Monterey or later. Tested on macOS 26 Tahoe.

Does Moonleaf drain laptop battery?

In our test on an M1 Pro running macOS 26.7.1, CPU stayed under 1% while playing a 1080p MP4. That is one machine and one file. We did not measure battery life on other Macs.

How do I bypass the macOS Gatekeeper quarantine prompt?

Official Moonleaf releases are code-signed with an Apple Developer ID and notarized by Apple. macOS Gatekeeper verifies the notarization ticket automatically, so Moonleaf opens directly on first launch. If you ever encounter a security prompt (e.g. after building from source or with strict custom security policies), you can right-click the app in Finder and choose Open, or run:
xattr -dr com.apple.quarantine /Applications/moonleaf.app
