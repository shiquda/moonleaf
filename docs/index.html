Frequently asked questions

Is moonleaf still maintained?

Yes. Upstream illufied/moonleaf was archived after v4.0.0, and this fork (shiquda/moonleaf) continues active development with notarized builds, Homebrew packaging, and Sparkle updates on macOS 12+ (tested on macOS 26 Tahoe).

Can I set a different wallpaper on each monitor and virtual Space?

Yes. Desktop Overview manages independent static wallpapers (.jpg, .jpeg, .png) per display and Space with startup recognition. Video (.mp4, .mov) and .gif wallpapers run via the native desktop overlay across connected displays.

Does Moonleaf support wallpaper playlists and usage history?

Yes. Create named playlists without copying files, choose sequential or random rotation (15 min, 1 hr, 3 hr, or Daily), switch lists from the menu bar, and browse up to 1,000 recent applies.

Does Moonleaf support Apple Silicon and Intel Macs?

The v4.2.0 release is a Universal binary for Intel (x86_64) and Apple Silicon (arm64) running macOS 12 Monterey or later (tested on macOS 26 Tahoe).

Does Moonleaf drain laptop battery?

In our test on an M1 Pro running macOS 26.7.1, CPU stayed under 1% while playing a 1080p MP4. That is one machine and one file; we did not measure battery life on other Macs.

How do I bypass the macOS Gatekeeper quarantine prompt?

Official releases are Apple Developer ID signed and notarized, so Gatekeeper verifies them automatically. For self-built binaries or strict policies, right-click moonleaf.app → Open, or run xattr -dr com.apple.quarantine /Applications/moonleaf.app.
